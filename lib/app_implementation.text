# Task Tracker - Implementation Summary

## Overview

Task Tracker is a Flutter task-management app built with:
- Provider for state management
- Firebase Auth for authentication
- Firestore for cloud sync
- Hive for offline task persistence
- SharedPreferences and secure storage for app settings and credentials
- flutter_local_notifications for local task reminders

The project currently includes the full user flow from onboarding to authenticated task management, profile, leaderboard, settings, and localized notifications.

## Architecture

### Presentation Layer
- `presentation/screens/` contains app UI
- `presentation/providers/` contains state and UI-facing logic
- reusable widgets live in `presentation/widgets/common/`

### Data Layer
- `data/models/` defines `UserModel`, `TaskModel`, onboarding models, and related enums
- `data/repositories/` handles authentication and task persistence/sync

### Core Layer
- `core/routes/` centralizes navigation
- `core/services/` contains storage and notification services
- `core/theme/` contains theme definitions
- `core/localization/` contains English and Hindi translations
- `core/constants/` contains app constants and storage keys

## Implemented Features

### 1. Authentication
- login with email and password
- sign up with email and password
- forgot password flow
- email verification flow
- remember me support
- logout flow

### 2. Onboarding
- three-page onboarding experience
- persistent completion state
- localized content

### 3. Task Management
- create task
- edit task
- delete task
- mark task complete or incomplete
- sort and filter tasks
- task categories and priorities
- overdue and due-today logic

### 4. Offline + Sync
- Hive stores user task data locally
- Firestore stores cloud task data
- repository performs robust two-way sync using task IDs and timestamps
- app remains usable offline with local task data

### 5. Notifications
- notification service initializes during app startup
- notification permission is requested during initialization
- task reminder scheduling is timezone-aware
- reminder notification fires at `reminderAt`
- end-of-task notification fires at task end time
- overdue summary notification can appear once per day
- completed and deleted tasks cancel scheduled reminders

### 6. Notification Reliability Improvements
- global Task Reminders toggle is persisted with SharedPreferences
- turning reminders OFF cancels all scheduled notifications immediately
- turning reminders ON re-schedules active future reminders for existing tasks
- Android scheduling uses `exactAllowWhileIdle` for better reliability under idle states
- exact alarm capability is requested when Android requires it

### 7. Battery Optimization Support
- Android-specific battery optimization status is checked through a native method channel
- settings screen provides a Battery Optimization row below Task Reminders
- tapping it opens the Android system settings screen for the app
- status is reflected back in the settings UI

Important:
- battery optimization cannot be fully toggled by Flutter alone
- Android requires user confirmation in system UI for this setting

### 8. Settings
- system / light / dark theme switching
- English / Hindi localization switching
- task reminder enable / disable
- battery optimization shortcut for Android
- delete all tasks action

### 9. Profile + Leaderboard
- profile setup and editing
- user statistics
- streak display
- leaderboard screen with ranked users

## Notification Logic Details

### Scheduling Conditions
A task reminder is scheduled only when:
- notifications are globally enabled
- the task has a reminder
- reminder time is still in the future
- task is not completed

### Cancellation Conditions
Scheduled notifications are cancelled when:
- the task is completed
- the task is deleted
- notifications are globally disabled
- the task no longer has a valid reminder

### Known OS Constraints
- Android battery saver / Doze can still delay notifications on some devices
- some OEMs apply stricter background policies than stock Android
- the app provides a battery optimization settings shortcut, but the final decision is system-controlled

## Localization + Theming

### Localization
- English and Hindi are implemented
- app strings include task flow, notifications, and settings text
- new battery optimization strings were added for both supported languages

### Theming
- Material 3 based theming
- responsive typography scaling for smaller phones and tablets
- settings UI uses the same theme-aware cards, icons, and text hierarchy across device sizes

## Current State of Documentation

This implementation summary reflects the current app behavior:
- no WorkManager-based reminder loop is part of the active notification flow
- reminder behavior is task-time-based, not periodic profile-configured polling
- settings now include both Task Reminders and Battery Optimization support

## Remaining Platform Realities

- Battery optimization changes require native Android settings UI.
- Notification delivery can still vary across OEM firmware.
- Widget tests currently need app-specific test setup because the default sample test does not initialize Firebase.
